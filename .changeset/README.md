# Changesets

This folder is managed by [changesets](https://github.com/changesets/changesets).

- `yarn changeset`: record a change (choose the bump and write a summary)
- `yarn run version`: apply pending changesets (bump the version and the changelog)
- `yarn release`: publish the package
- `yarn changeset status`: show what would be released

Add a changeset for any change a consumer would notice. Docs, tests, CI, and internal refactors need none.
